8. SITA AI — PERSONALIZED GEMINI
==================================================

The Gemini API integration already exists.

Now make it properly integrated with the user's authenticated SITA context.

When a user asks SITA something, the backend should:

1. Verify the authenticated user.
2. Retrieve only the relevant data belonging to that user.
3. Build appropriate context.
4. Send the minimum necessary context to Gemini.
5. Receive the response.
6. Save the conversation to Supabase.
7. Return the response to the frontend.

The AI must NEVER receive another user's information.

The AI should be capable of handling:

- General women's health questions
- Period questions
- Cycle questions
- PCOS-related screening conversations
- Symptom discussions
- Basic symptom triage
- Mood/wellbeing questions
- Pregnancy questions
- Postpartum questions
- Questions about the user's own tracked data

Keep the existing unified SITA AI interface.

Do NOT create separate chatbot pages.

9. AI BEHAVIOR
==================================================

SITA is an AI health-information and assistance system.

It must not claim to diagnose medical conditions.

For example, never respond:

"You have PCOS."

Instead explain that symptoms may be associated with PCOS and recommend appropriate professional evaluation.

Do not prescribe medication.

Do not invent medical facts.

Acknowledge uncertainty.

For potentially serious symptoms, provide appropriate guidance to seek professional medical care.

Keep this behavior in the server-side AI system instructions, not merely in frontend text.
